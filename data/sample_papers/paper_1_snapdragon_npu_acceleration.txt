# Hardware-Aware Retrieval-Augmented Generation on Snapdragon X Elite: Benchmarking On-Device Hexagon NPU vs. Mobile GPUs

**Authors**: Dr. Evelyn Reed, Marcus Chen, Devante Washington
**Affiliation**: Edge AI Systems Laboratory, Cambridge Institute of Technology
**Date**: February 2025

---

### Abstract
On-device Retrieval-Augmented Generation (RAG) represents a transformative paradigm for private document intelligence, enabling local inference without cloud transmission. However, mobile and laptop processors often suffer from thermal throttling and memory bandwidth constraints when executing transformer workloads. In this paper, we evaluate hardware-aware optimization strategies for RAG pipelines executing on the Qualcomm Snapdragon X Elite platform equipped with the 45 TOPS Hexagon Neural Processing Unit (NPU). By compiling quantized transformer architectures into Qualcomm Neural Network (QNN) execution contexts and employing integer-quantized vector similarity kernels, our architecture achieves an average time-to-first-token (TTFT) of 18.4 ms and a generation throughput of 38.6 tokens/second for sub-3B parameter instruction models. When compared to integrated mobile GPUs, the Snapdragon Hexagon NPU yields a 4.2x improvement in energy efficiency (joules per token) and reduces thermal dissipation by 37%.

---

### 1. Introduction
Retrieval-Augmented Generation has emerged as the standard architecture for grounding Large Language Models (LLMs) on private corpora. Traditional implementations offload both embedding generation and generative inference to remote data centers. However, for sensitive domains—including legal analysis, proprietary financial auditing, and confidential scientific research—cloud-based processing introduces unacceptable security risks and regulatory compliance hurdles.

The advent of dedicated neural processing units in edge devices, such as the Snapdragon X Elite computing platform, enables local execution of multi-billion parameter neural networks. The key technical challenge lies in bridging the computational gap between unquantized floating-point pipelines and specialized fixed-point NPU tensor accelerators.

---

### 2. Architecture & Qualcomm Hexagon NPU Integration
Our proposed framework, Snapdragon-Edge-RAG, is composed of four hardware-targeted layers:

1. **Document Ingestion & Chunking**: A page-aware sliding window segmentation engine operating with 500-character windows and 80-character boundary overlaps.
2. **Quantized Dense Embedding Engine**: An ONNX-exported `all-MiniLM-L6-v2` transformer model executed via the ONNX Runtime QNN Execution Provider on the Hexagon NPU, generating 384-dimensional dense vectors.
3. **Hardware-Accelerated Vector Index**: An in-memory FAISS flat index utilizing normalized Inner Product operations for exact cosine similarity calculation.
4. **QNN Quantized Generative LLM**: A 4-bit integer quantized (INT4-AWQ) instruction-tuned model executed directly on the Snapdragon Hexagon Tensor Core with dedicated direct memory access (DMA).

---

### 3. Methodology & Experimental Setup
We conducted extensive benchmarks comparing four hardware execution targets on an HP OmniBook X laptop powered by the Qualcomm Snapdragon X Elite (SC8380) with 32 GB LPDDR5x RAM:

- **Target A**: Snapdragon Hexagon NPU via Qualcomm QNN Execution Provider (INT4 / FP16 mixed precision).
- **Target B**: Integrated Qualcomm Adreno GPU via Windows DirectML.
- **Target C**: Snapdragon Oryon CPU (12 cores) executing multi-threaded ARM64 NEON SIMD instructions.
- **Target D**: Standard x86_64 Mobile Processor (Reference Baseline).

---

### 4. Evaluation Dataset & Benchmark Metrics
We evaluated retrieval precision and generation fidelity across two standardized research benchmarks:
- **HotpotQA Edge Subset**: 2,500 multi-hop reasoning questions over technical scientific corpora.
- **ResearchPilot-Bench-5k**: A curated corpus of 5,000 academic research papers spanning computer science, quantum physics, and biomedical engineering.

Key metrics evaluated include:
- **Time to First Token (TTFT)** in milliseconds.
- **Generation Throughput** in tokens per second (tok/s).
- **Energy Consumption** measured in milliwatt-hours per 1,000 generated tokens.
- **Retrieval Mean Reciprocal Rank (MRR@5)** and Citation Accuracy (%).

---

### 5. Experimental Results
The experimental results demonstrate substantial performance and efficiency gains when utilizing the Snapdragon Hexagon NPU:

| Hardware Target | Backend / Provider | TTFT (ms) | Throughput (tok/s) | Power Draw (W) | Citation Accuracy |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Snapdragon Hexagon NPU** | **QNN INT4 HTP** | **18.4 ms** | **38.6 tok/s** | **4.8 W** | **94.2%** |
| Integrated Adreno GPU | DirectML FP16 | 32.1 ms | 24.2 tok/s | 14.2 W | 93.8% |
| Snapdragon Oryon CPU | ARM64 NEON | 48.7 ms | 16.5 tok/s | 18.5 W | 93.1% |
| x86_64 Mobile CPU | OpenVINO / CPU | 64.2 ms | 11.2 tok/s | 28.0 W | 92.5% |

The Snapdragon Hexagon NPU completed complex multi-source RAG queries with an average end-to-end latency of 142 ms (including hybrid vector retrieval), while maintaining a thermal profile under 41°C across extended stress testing.

---

### 6. Limitations & Future Work
While the Hexagon NPU delivers exceptional energy efficiency and token throughput, current compilation tools require fixed tensor shapes for pre-allocated KV-cache buffers. Dynamic sequence lengths exceeding 4,096 tokens require segmented context swapping, which introduces marginal memory copy overhead. Future investigations will focus on dynamic block-paged KV-caching directly within the Hexagon NPU direct-access scratchpad memory.
